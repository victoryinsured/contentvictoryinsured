# Content Quality Checklist

Before a script is approved:

- [ ] Would Victoria actually say this?
- [ ] Can Victoria stand behind every claim?
- [ ] Is there a clear point?
- [ ] Is the hook specific rather than generic?
- [ ] Does it teach, reveal, challenge, or entertain?
- [ ] Is there a concrete example when one would help?
- [ ] Does it avoid unnecessary jargon?
- [ ] Does it avoid sounding copied from another creator?
- [ ] Is it appropriate for the intended platform?
- [ ] Does the CTA fit the content?
- [ ] Is there anything that should be added to the POV library after approval?
