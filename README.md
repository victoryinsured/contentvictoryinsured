# Victory Content Intelligence

This repository is the source of truth for Victory Insured's content intelligence system.

## Goal
Build a repeatable content machine that produces TikTok, Instagram, and YouTube content that sounds like Victoria, reflects beliefs she actually stands behind, and can eventually generate daily scripts automatically.

## Build order
1. Victoria DNA
2. Creator research
3. Content topics
4. Script formulas
5. Platform rules
6. Content brain
7. Approved/rejected examples

Do not automate script generation until the content brain has enough approved examples and POV intelligence.
