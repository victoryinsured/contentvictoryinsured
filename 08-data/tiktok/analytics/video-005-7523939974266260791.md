## Why this matters

The video's success appears tied to:
- exact high-intent topic
- step-by-step framing
- concrete compensation claim ($4,000/week)
- "how to get started" language
- claims-adjuster keywords that map directly to user searches
- high reference value, reflected in extremely strong saves
- follow conversion from a useful educational answer

## Important performance interpretation

The 4.5% full-video completion rate should not automatically be treated as failure.

Despite low full completion, the video:
- reached 212K views
- generated ~13K saves
- produced 1.3K new followers
- was discovered primarily through search

This indicates that search intent + usefulness can produce strong business/content outcomes even when completion rate is not unusually high.

## Content Brain rule

Do not evaluate every video using the same metric hierarchy.

For **searchable educational content**, prioritize:
1. Search traffic
2. Saves
3. New followers
4. Shares
5. Relevant comments/questions
6. Average watch time / retention
7. Likes

For **7-second trend content**, use a different metric hierarchy centered on reach, profile curiosity, completion/replays, shares, and qualified profile visits.

## Reusable formula

SEARCHABLE QUESTION / DESIRE
→ DIRECT PROMISE
→ STEP-BY-STEP ANSWER
→ SPECIFIC MONEY / ROLE / OUTCOME
→ IMPORTANT NUANCE
→ NEXT ACTION
