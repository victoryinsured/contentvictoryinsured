# Combined Creator DNA

Victoria's ideal content does NOT come from one creator.

It combines four qualities:

**USEFUL**
+
**HUMAN**
+
**TECHNICALLY SMART**
+
**COMMERCIALLY STRATEGIC**

Or:

**JUSTINE TAKEAWAY**
+
**GABRIELA PERSONALITY**
+
**MADDIE TECHNICAL DEPTH**
+
**SHELBY CAREER-MONEY FUNNEL STRATEGY**

Then filter all of it through:
- Victoria's voice
- claims expertise
- faith when authentic
- money specificity
- audience language
- Victory blue-ocean positioning

## Important anti-copy rule
Never generate:
"Make a video like [creator]."

Instead ask:
**Which capability from Victoria's creator influence map does this piece need?**

Examples:
- Search tutorial → Utility + Technical
- Personal career story → Personality + Commercial
- Claims Corner → Technical + Utility + Personality
- Webinar promo → Commercial + Personality
- 7-second trend → Personality + Qualified-Reach strategy
