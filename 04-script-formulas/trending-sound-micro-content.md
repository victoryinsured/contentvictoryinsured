# Trending Sound Micro-Content Formula

## Purpose
Create fast, low-production TikToks that use current sounds to increase consistency, reach, curiosity, and profile discovery while still reinforcing Victoria's core positioning.

## Core formula
CURRENT TRENDING SOUND → ONE-LINE ON-SCREEN MESSAGE → SPECIFIC TRANSFORMATION / OPPORTUNITY / RESULT

## Proven sub-formulas

### 1. Opportunity reaction
Trending sound + "When you're offered..." + specific claims job + specific compensation.

### 2. Transformation
Trending sound + "When you think about..." + before state + after state + concrete career/income result.

### 3. Identity transformation
Trending sound + specific hardship + faith/action + career transformation.

## Content Brain rules
- Trend must be current enough to feel native, not stale.
- The text must still make sense with the sound's emotional tone.
- Do not chase a trend that has no natural connection to Victoria's story, audience, or offer.
- Keep on-screen copy understandable within a few seconds.
- Use concrete nouns and numbers when authentic.
- Include niche classification language when possible: claims adjuster, insurance claims, career change, etc.
- Prefer one idea per video.
- These should often be 5–10 seconds.
- Treat these as profile-magnet / reach content, not the only content type.

## Trend selection criteria
A sound is useful when:
1. It is currently gaining traction.
2. Its emotional tone matches one of Victoria's proven themes.
3. It can support a one-line message without explanation.
4. The resulting post still points toward the audience Victoria wants.

## Proven themes for trend pairing
- Claims income / opportunity
- Career transformation
- Faith + breakthrough
- Single motherhood + mobility
- From hardship to high income
- "Nobody told me this" career discovery
- Claims-adjuster lifestyle / deployments / contracts
